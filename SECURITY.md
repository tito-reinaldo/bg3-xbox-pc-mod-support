# Security policy

## Report a vulnerability privately

Use [Report a vulnerability](https://github.com/tito-reinaldo/bg3-xbox-pc-mod-support/security/advisories/new) to contact this repository's maintainers privately. A GitHub account is required.

Include:
- The package version and affected component.
- What could go wrong and the conditions needed.
- Safe steps to reproduce the problem, with a small example if possible.
- Relevant log excerpts with account details, tokens, and personal paths removed.

Please avoid posting exploit details in a public issue while a report is being investigated. Ordinary crashes, mod conflicts, and setup questions belong in the bug report form.

For an antivirus detection, include the security product, detection name, package version, and affected filename. Keep the file blocked while it is investigated.

## Supported versions

Reports are welcome for every published version. Fixes target the latest experimental release; older releases do not have separate security maintenance. Package 0.2.2 currently targets BG3 build 4.1.1.7445165 and Microsoft Store package 1.8.907.0 on Windows PC.

This project is maintained in spare time, so response and fix dates cannot be guaranteed. Reports will be assessed, and confirmed problems may require coordination with the affected component's upstream maintainers. Public disclosure can be discussed in the private report.

Only test on systems and files you own or have permission to test.
