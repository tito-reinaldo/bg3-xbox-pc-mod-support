# Build instructions

Download **BG3-Xbox-PC-Corresponding-Source-0.2.2.zip** from the [0.2.2 source release](https://github.com/titoreinaldo/bg3-xbox-pc-mod-support/releases/tag/v0.2.2), extract it, and follow the **BUILDING.md** at the archive's root. It contains the complete component sources, build helpers, dependency records, and setup tests for package 0.2.2.

This repository checkout and GitHub's automatic source ZIPs do not contain those complete component sources. The current package starts `App/BG3ModManager.exe` directly; the former outer launcher is no longer shipped.

The [0.1.0 validation record](Developer/Historical/VALIDATION-0.1.0.md) is kept as historical evidence. The old installer and its tests remain in the [v0.1.0 tag](https://github.com/titoreinaldo/bg3-xbox-pc-mod-support/tree/v0.1.0).
